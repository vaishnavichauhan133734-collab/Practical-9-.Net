# Practical 9 - .NET Technologies

ASP.NET Web Forms placement management application.

## Prerequisites

- Visual Studio 2022
- .NET Framework 4.8
- SQL Server LocalDB
- IIS Express

## Database setup

1. Open SQL Server Object Explorer or SQL Server Management Studio.
2. Run `Database/PlacementDB.sql`.
3. Confirm that `Web.config` contains the LocalDB connection string.

## Run

Open `Practical9.csproj` in Visual Studio and press **F5**.

## Pages

- `Default.aspx`: placement summary dashboard
- `Companies.aspx`: placed student records
